# Saintbit Mate

Demo web educativa de **matemáticas para enseñanza básica**: un estudiante elige su nivel, practica con material de 1°
básico, resuelve desafíos gamificados y el docente revisa una vista de analítica de uso.

> Prototipo de interfaz (front-end), sin servidor: todo funciona en el navegador.

## Secciones

| Página | Qué muestra |
|---|---|
| `login.html` | Ingreso a la demo |
| `home.html` | Elección del nivel educativo |
| `1_basico.html` | Contenidos y material de 1° básico (guías, cuadernos de trabajo y evaluaciones en PDF) |
| `gamificacion.html` | Desafíos gamificados con puntaje |
| `IAadpatativa.html` | Propuesta de ejercicios adaptativos |
| `analitica.html` | Analítica de usuarios para el docente |

## Tecnologías

HTML5 · CSS3 · JavaScript (sin frameworks)

## Cómo verla

1. Descarga o clona el repositorio.
2. Abre `saintbit-math-education-demo/home.html` en el navegador (o usa la extensión *Live Server* de VS Code).

## Material

Los PDF de `assets/pdfs` son guías, cuadernos de trabajo y evaluaciones de matemática de 1° básico, usados como contenido de
ejemplo de la demo.
